# 美食食谱 · Recipe Mini App

> 今天吃什么？翻开食谱就知道。
> 一个微信小程序：菜谱浏览 + 分类检索 + 幸运一签 + 美食动态（做菜记录）。

## 功能

- **菜谱库**：20+ 道家常菜谱，食材、步骤全部手工撰写，支持按菜类/搜索检索
- **详情页**：食材清单、分步做法、难度/耗时标签
- **幸运一签**：不知道吃什么时，摇一签由老天决定
- **美食动态**：官方菜谱号每日推荐 + 「我的做菜记录」（可发图、本地持久化、点赞收藏）
- **本地账号**：注册/登录/记住账号（密码哈希存储，不明文落盘）

## 技术栈

- 原生微信小程序（无第三方框架）
- 数据：本地 Storage + `data/recipes.js` 菜谱数据
- 自定义 tabBar（首页/菜类/动态/搜菜/个人）

## 目录结构

```
├── app.js / app.json / app.wxss
├── custom-tab-bar/          # 自定义 tabBar
├── data/recipes.js          # 菜谱数据（20+ 道完整菜谱）
└── pages/
    ├── index/               # 首页（热门推荐 + 快速分类）
    ├── category/            # 菜类浏览
    ├── dynamic/             # 美食动态（官方号 + 我的记录）
    ├── search/              # 搜索
    ├── lucky/               # 幸运一签
    ├── profile/             # 个人中心
    ├── detail/              # 菜谱详情
    ├── login/               # 登录/注册
    └── *-likes / *-favorites / following / followers   # 我的收藏与关注
```

## 运行

微信开发者工具 → 导入项目 → 选择本目录 → 编译运行。纯本地数据，无需任何后端。
